# openprovider_domain_check (Data Source)

Checks whether a domain is available to register. Unlike the `openprovider_domain` data source, this asks the registry, not the account: a domain somebody else holds is reported as taken rather than as an error.

## Example Usage

```terraform
data "openprovider_domain_check" "example" {
  domain = "example.com"
}

# Register the domain only where nobody holds it yet.
resource "openprovider_domain" "example" {
  count = data.openprovider_domain_check.example.available ? 1 : 0

  domain       = "example.com"
  owner_handle = "XX000000-NL"
}
```

### Required

### Read-Only

- `available` (Boolean) Whether the domain can be registered (`status` is `free`).
- `id` (String) The domain identifier (domain name).
- `is_premium` (Boolean) Whether the domain is a premium domain, priced above the extension's standard price.
- `reason` (String) The registry's reason for the status, where it gives one.
- `status` (String) The availability status the registry reports: `free` when the domain can be registered, `active` when somebody holds it.
