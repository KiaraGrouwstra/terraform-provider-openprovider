# openprovider_domains (Data Source)

Lists the domains the account holds. With `full_name` set, the list holds that domain or is empty, where the `openprovider_domain` data source errors on a domain the account does not hold.

## Example Usage

```terraform
# Every domain the account holds.
data "openprovider_domains" "all" {}

# One domain, or nothing: an empty list where the account does not hold it.
data "openprovider_domains" "example" {
  full_name = "example.com"
}

locals {
  held = length(data.openprovider_domains.example.domains) > 0
}
```
